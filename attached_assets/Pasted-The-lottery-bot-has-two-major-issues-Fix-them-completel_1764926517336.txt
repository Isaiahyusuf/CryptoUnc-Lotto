ISSUE 1 — WALLET DUPLICATION
===========================================================
The bot currently creates a new wallet every time the user taps “Play”.  
This is wrong. The bot must SAVE the wallet (created or imported) permanently so it never creates more than one wallet for that user unless they explicitly add more.

Required behavior:
1. When a player creates or imports a wallet, SAVE it to the database.
2. When the user taps “Play”, the bot must check if the user already has a wallet saved.
3. If a wallet exists, reuse it. DO NOT create a new wallet.
4. Only create a wallet if user has zero saved wallets.
5. If the app allows multiple wallets, enforce a limit (max 3 wallets) and never exceed that limit.

Database requirements:
Add a “wallets” table:
- id
- telegram_user_id
- wallet_address
- private_key (encrypted or stored securely, only if generated by bot)
- created_at

Code requirement:
Refactor all wallet creation logic so it first queries the database:
user_wallets = db.get_wallets(user_id)
if len(user_wallets) > 0:
    use existing wallet
else:
    create wallet and save

Remove any code that auto-creates a wallet without checking the database.
