Automatic SOL Payment and Refund System

Goal:
Make the bot automatically send SOL to winners and refund players safely without manual actions.

⸻

Step 1: Create a Bot Wallet
	•	Generate one Solana wallet that will act as the bot’s main wallet.
	•	Fund this wallet with enough SOL to handle prize payments and refunds.
	•	Save the private key of this wallet securely in the project environment or secrets section.
	•	The bot will use this private key to sign and send real Solana transactions.

⸻

Step 2: Enable Automatic Prize Payments
	•	After each round ends and the winner is selected, the bot should automatically send the correct prize amount of SOL from the bot’s wallet to the winner’s wallet address.
	•	Once the transaction is sent successfully, the bot should confirm it by posting a message in the Telegram group showing the winner’s name, prize amount, and a short form of the wallet address.
	•	This ensures that winners are paid instantly and transparently.

⸻

Step 3: Add a Refund System
	•	If a round does not reach the minimum number of players, it should be marked as “failed.”
	•	The bot should then automatically return each player’s SOL back to their wallet.
	•	After all refunds are complete, the bot should post a message confirming that the round was cancelled and everyone was refunded.
	•	This guarantees fairness and prevents users from losing money if a game round doesn’t start properly.

⸻

Step 4: Add Safety Checks Before Sending SOL
	•	The bot must always check its wallet balance before attempting to pay or refund anyone.
	•	If the wallet doesn’t have enough SOL, it should log a warning and skip the transaction until more funds are added.
	•	To prevent transaction overlaps, the bot should process one payout or refund at a time, using a safe queue or delay system.

⸻

Step 5: Transaction Verification and Logging
	•	Every time the bot sends a payment or refund, it should record the transaction signature, amount, receiver address, and round ID in the database.
	•	This helps in verifying later that payments were actually completed.
	•	If any transaction fails, it should retry up to a few times, then mark it as “pending manual review.”

⸻

Step 6: Testing and Launch
	•	First, test everything on Solana Devnet using test SOL.
	•	Verify that the bot can pay winners and refund players correctly.
	•	Once confirmed, switch the RPC to Solana Mainnet and fund the bot wallet with real SOL.
	•	Do a small live test round before going fully public.

⸻

Step 7: Maintenance and Transparency
	•	Always monitor the bot wallet to ensure it has enough SOL for payouts.
	•	Keep all transaction logs visible to the admin only.
	•	Optionally, display a “last payout” message or leaderboard in the group for transparency.
