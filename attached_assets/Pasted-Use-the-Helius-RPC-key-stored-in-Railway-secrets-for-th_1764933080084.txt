Use the Helius RPC key stored in Railway secrets for the primary RPC. Retrieve it from the environment variable (for example, process.env.HELIUS_RPC) so it is never hardcoded. Use https://api.mainnet-beta.solana.com as the fallback RPC in case the primary fails or is slow. The bot should automatically switch to the fallback if there is any RPC error. Before performing any transaction, always check the correct SOL balance for the wallet by fetching lamports and converting to SOL. Log the wallet being checked to ensure the bot is using the correct wallet. Include the amount to send plus a network fee of about 0.00002 SOL when checking for sufficient balance. If the balance is below this threshold, do not attempt the transaction and return a message indicating insufficient balance. To fix the recent_blockhash error, always fetch the latest blockhash from the RPC right before creating the transaction and pass it when building the transaction; never assign tx.recent_blockhash directly. After creating the transaction, send it and confirm it using finalized commitment to ensure it completes successfully. When a user creates or imports a wallet, first check if a wallet already exists in the database and reuse it if it does; otherwise, create or import a new wallet and save it to the database to prevent multiple wallets for the same user. For automatic sending of SOL, always check that the wallet has enough balance including network fees before sending, fetch the latest blockhash, build the transaction with the instruction, send the transaction, and confirm it finalized. Always log wallet address, balance, amount being sent, and RPC endpoint for debugging. Ensure all environment variables from Railway (including the Helius RPC key) are used directly, so no secrets are hardcoded. Following these steps ensures the bot shows the correct SOL balance, avoids insufficient balance errors, fixes the recent_blockhash problem, safely handles automatic SOL transactions, saves and reuses wallets properly, and reliably uses Helius with a fallback RPC while being fully compatible with Railway hosting.
